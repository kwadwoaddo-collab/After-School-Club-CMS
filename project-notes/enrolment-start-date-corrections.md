# Correct an enrolment start date

1. Open **Students**, find the student and open their profile.
2. Find **Enrolment and follow-up** and choose **Edit start date**.
3. Enter the **Actual enrolment start date** and a meaningful **Reason for correction** (at least five characters).
4. Choose **Save start date**, then check the displayed enrolment start date.

The date must be between 1 January 1900 and today. Editing is available for confirmed enrolments to an Owner or authorised Manager; Managers must have access to the student's centre. If the date changed while you were editing, or saving was not confirmed, reload the profile and review the current date before retrying.

This corrects the original attendance start date and records an audit entry with the previous date, corrected date, reason and actor. It does not change fees, billing dates, enrolment status or status history; create invoices; or send emails.

The original start date is separate from the effective dates of a pause, stop or reactivation. Use **Change enrolment status** for those lifecycle events. A start-date correction does not clear a billing-review hold: an Owner or Manager must separately review the actual fee and agreed restart date in **Billing configuration**.
