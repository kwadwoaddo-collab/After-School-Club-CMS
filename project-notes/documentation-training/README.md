# SprintScale CMS — Master Documentation & Training Programme

Welcome to the official documentation and training library for **SprintScale After-School-Club-CMS**.

This documentation programme provides an evidence-backed, operational source of truth for club organisation owners, centre managers, front-desk administrators, classroom tutors, and registered parents.
